About this viewer

A feature-centric genome browser for sparse-autoencoder (SAE) features, selectable from the dictionary switcher. Each dictionary was scored on the same annotated prokaryotic genome panel in one coordinate frame, so the annotation tracks and structures apply to each. Pick a feature to browse the genomic windows where it fires most strongly, each an IGV-style track stack with the feature's dense per-nucleotide activation aligned to gene/CDS, Pfam domain, CATH fold, TED fold, RNA gene, regulatory (promoters / RBS / terminators), operon, replication (oriC / ter / DnaA boxes), sequence-motif, codon-position, GC, low-complexity, nucleotide, and amino-acid tracks. A track appears whenever one of its spans falls in the current window.

How to use

  • Left — search / sort / filter features by enrichment fold, fire count, activation, and more. Click a feature to load it.
  • Top — the feature's detected annotations (Pfam families, CATH/TED folds, and genomic layers) with precision-fold, recall, and FDR-q, its annotation context vs background, optional annotation-context correlations, and its nucleotide + amino-acid logos (built on the gene reading strand).
  • Main — page exemplars (◄ ►), then zoom (buttons or mouse-wheel) and pan (drag) from the full region down to single nucleotides; nucleotide and amino-acid letters appear when zoomed in. Every track stays coordinate-aligned at all zoom levels. Hover a gene / domain / RNA for its full name.
  • Protein / structure — for coding exemplars, the panel below the tracks lists the gene's GO terms and loads the protein's 3D structure from a precomputed offline cache, badged by source (AlphaFold DB) with the model's mean pLDDT. A color switch shades the structure either by the feature's dense activation (viridis, dark = low → yellow = high, gray = inactive) or by CATH / TED fold domain. The 3D loads in the background and never blocks the rest of the view. The panel distinguishes three states: a rendered structure; "no structure available" for a coding protein with no AlphaFold DB model (these can be folded later); and "no structure expected" for a non-coding feature (no protein). The header reports the per-dictionary structure coverage — the share of coding exemplars with a precomputed model.

Reading the activation track

Where a dense re-harvest exists, the activation track is the feature's dense per-nucleotide profile (a continuous filled curve, coordinate-accurate at nt zoom). Otherwise it shows the sparse retained-firing track (stems at the harvest's retained positions; the row is labeled "activation (sparse)"). The annotation tracks are dense and exact in both cases.

Reading the logos

The nucleotide and amino-acid logos are oriented to the gene reading strand (so a coding motif reads in-frame), but the model reads the firing strand. Many features fire antisense to their genes; for those the model's actual input is the reverse complement of the motif shown. Each feature reports the fraction of coding exemplars that fire sense vs antisense.

Provenance

This app is fully self-contained and offline: the same folder (viewer + data + precomputed structures in af_cache/) runs as a standalone static site (see README.md). No panel makes a live network call at view time.
